### 1. Управление клиентами:

1.1. **Регистрация клиента:**

- **Источник требования:** Частный клиент.
- **Описание требования:** Реализовать функционал создания посылки через веб-интерфейс. Поля для заполнения:
  - ФИО (Обязательные поле)
  - Телефон (Обязательное поле)
  - Адрес (Обязательное поле)
  - e-mail
- **Приоритет требования:** Высокий.

---


### 2. Управление посылками:

2.1. **Оформление отправки посылки:**

- **Источник требования:** Частный клиент.
- **Описание требования:** Реализовать функционал создания посылки через веб-интерфейс. Поля для заполнения:
  - Данные отправителя (ФИО, телефон, адрес) (Обязательные поля)
  - Данные получателя (ФИО, телефон, адрес) (Обязательные поля)
  - Вес посылки (в кг) (Обязательное поле)
  - Габариты (длина × ширина × высота в см) (Обязательное поле)
- **Приоритет требования:** Высокий.

---

### 3. Управление статусами:

3.1. **Ручное обновление статуса посылки:**

- **Источник требования:** Менеджер (специалист службы поддержки).
- **Описание требования:** Предоставить возможность менеджеру вручную изменять статус посылки в админ-панели по трек-номеру. Доступные статусы:
  - Принято
  - В пути
  - Ожидает вручения
  - Доставлено
- **Приоритет требования:** Высокий.

3.2. **Отслеживание статуса посылки по трек-номеру:**

- **Источник требования:** Менеджер (специалист службы поддержки).
- **Описание требования:** Обеспечить возможность отслеживания текущего статуса посылки по её трек-номеру через админ-панель.
- При вводе трек-номера система отображает:
  - Текущий статус
  - Адрес доставки
  - Имя получателя
- Если посылка не найдена — выводится сообщение: "Посылка с таким номером не найдена".
- **Приоритет требования:** Высокий.

3.3. **Нотификация о сменен статуса:**

- **Источник требования:** Менеджер (специалист службы поддержки).
- **Описание требования:** Предоставить возможность менеджеру вручную изменять статус посылки в админ-панели. Доступные статусы:
  - Принято
  - В пути
  - Ожидает вручения
  - Доставлено
- Статус обновляется в системе, и клиенту автоматически отправляется уведомление.
- Поиск посылки возможен по трек-номеру.
- **Приоритет требования:** Средний.

---

### 4. Формирование отчётов:

4.1. **Формирование отчёта по посылкам:**

- **Источник требования:** Менеджер.
- **Описание требования:** Реализовать функцию формирования отчёта по посылкам с фильтрацией по следующим параметрам:
  - Статус посылки
  - ФИО отправителя
  - ФИО получателя
- Результат отображается в виде таблицы со столбцами:
  - Трек-номер
  - Отправитель
  - Получатель
  - Адрес доставки
  - Текущий статус
- При отсутствии данных — отображается сообщение: "Нет посылок, соответствующих условиям".
- **Приоритет требования:** Средний.
